# صالون المقص الذهبي - بن فريحة، وهران 💈
### موقع ويب ثابت متكامل (Static Website) متوافق 100% مع GitHub Pages

موقع ويب عصري ومتكامل لصالون حلاقة رجالي ببن فريحة، ولاية وهران. الموقع مبني ليكون **موقع ويب ثابت (Client-Side Static Website)** يعمل بالكامل على المتصفح عبر **HTML5 و CSS3 و JavaScript** بدون الحاجة لأي خادم خلفي (Node/PHP/Python) أو قاعدة بيانات مدفوعة، وهو مهيأ ومضبوط ليعمل مباشرة وبكل سلاسة على **GitHub Pages**.

---

## 🚀 كيفية النشر على GitHub Pages (طريقتان سهلتان):

### الطريقة الأولى: النشر التلقائي عبر GitHub Actions (الأسهل والموصى بها)
تم إعداد ملف العمل التلقائي `.github/workflows/deploy.yml` مسبقاً في المشروع:
1. قم برفع المشروع (Push) إلى مستودعك على GitHub في فرع `main`.
2. ادخل إلى إعدادات المستودع: **Settings** > **Pages**.
3. في خيار **Source** (المصدر)، اختر: **GitHub Actions**.
4. سيتولى غيتهوب بناء الموقع ونشره تلقائياً على الرابط:
   `https://<username>.github.io/<repository-name>/`

---

### الطريقة الثانية: النشر اليدوي عبر مجلد `dist`
الموقع يقوم بإنشاء ملفات HTML و CSS و JS جاهزة ومستقلة تماماً داخل مجلد `dist/`:
1. قم بتشغيل الأمر:
   ```bash
   npm run build
   ```
2. سينتج مجلد اسمه `dist` يحتوي على:
   - `index.html` (ملف الموقع الرئيسي بمسارات نسبية `./`)
   - `assets/` (ملفات الجافاسكريبت والأنماط والصور المجمعة)
   - `404.html` (ملف التوجيه لصفحات غيتهوب)
3. يمكنك رفع محتويات مجلد `dist` مباشرة إلى فرع `gh-pages` أو رفعها في المستودع الرئيسي واختيار مجلد `dist` في إعدادات **GitHub Pages**.

---

## 🛠️ التجهيزات التقنية المطبقة لدعم GitHub Pages:
- **المسارات النسبية (`base: './'`)**: تم ضبط Vite ليعمل بمسارات نسبية `./assets/` حتى لا تواجه أي خطأ 404 عند استضافة الموقع داخل مسار فرعي للمستودع.
- **تضمين الصور**: تم استيراد وضغط جميع صور الحلاقين والمحل ووضعها في مجلد `public/images` ليتم تضمينها تلقائياً داخل الحزمة الثابتة.
- **ملف `404.html`**: لمنع حدوث أي خطأ عند تحديث الصفحة أو استخدام الروابط الداخلية.
- **التخزين المحلي (LocalStorage)**: يتم حفظ المواعيد وقرارات الحلاقين وكلمات السر والإعلانات وإحصائيات الزوار محلياً في متصفح المستخدم دون الحاجة لسيرفر.

---

## ✂️ مميزات الموقع:
1. **عرض طاقم الحلاقين (كريم، يوسف، سامي)** مع صورهم وتخصصاتهم وساعات عملهم.
2. **نظام حجز مواعيد تفاعلي** باليوم والوقت مع إمكانية استعلام الزبون عن حالة موعده برقم هاتفه.
3. **لوحة تحكم الحلاقين**: يدخل كل حلاق باسم مستخدم وكلمة سر خاصة به لمراجعة وقبول أو رفض المواعيد.
4. **واجهة صاحب الصالون برابط خاص (`#owner-portal`)**:
   - إضافة وتعديل الحلاقين وتزويدهم ببيانات الدخول.
   - قسم إعلانات HTML متعدد الأماكن في الموقع (لصق كود HTML ومعاينته مباشرة).
   - عداد وإحصائيات زوار الموقع.
5. **موقع المحل في بن فريحة، وهران**: خريطة تفاعلية وزر تشغيل الملاحة في Google Maps مباشرة.
